# shot-exam 细则

## 题型怎么认

题干里已经写了"（单选题）""（不定项选择）""（判断题）"的，以标注为准。没标注才看选项控件和问法：

| 问法 | 题型 | 写几个 |
|---|---|---|
| "是：""正确的是""最高能到" | 单选 | 一个字母 |
| "哪些""包括""下列几项" | 不定项 | 两个以上，升序连写 |
| 陈述句后面接对/错 | 判断 | "对"或"错" |

## 依据写到什么程度

能被人拿去核对的一句就够，落到公式、定义、年份、条文号、数量关系上。

写得出：`每公里接头数 = 2×1000/L，L=12.5 m 时是 160`

写不出："这是常识""教材上大概这么写"

## 两种口径打架

课程教材和行业标准给的答案不一样时，主答案给教材口径（判分是教材判的），同一行补一句备选和差异来源。单选题如果是自动判卷，把备选写进依据里，别写进答案里——判卷机不认。

```
1. 答案：C
   依据：62 号道岔侧向 220 km/h（哈大客专），是我国最高；只讲到 42 号道岔的教材记 160 km/h。
```

## 常掉的坑

工程类：号码和速度的对应、规划的版本年份（四纵四横 2008、"八纵八横" 2016）、把企业宣传口径当成标准结论。

C 和算法：逗号表达式只留最后一个值、`int` 溢出（12! 之后失效）、整数除法截断、除零、`long long` 顶到 20!、循环少算或多算一次。

数学：下标从 0 还是 1、题里的"两个月后"到底是第几个月、保留位数和进位方向。

通用：单位（km/h、m、mm）、"最长/最高/最先进"这类绝对说法对应的年份。

## 拿不准的时候

高置信直接给。中等就在依据里点明假设。低的话答案后面加"（存疑）"，写清缺哪条信息才能定。图糊到读不出选项，说读不出，不要编选项。

## 汇总行

以 `汇总：` 开头，题号升序，项之间一个空格。单选和判断写单字符，不定项字母升序连写。判断题只写"对""错"，不写 √、T、"正确"。正文和汇总对不上，以正文为准并修掉汇总。

## 图不止一张

单图多题，按图上编号。多图先给全局题号再逐题答；题号重复就加"图2-1"这类前缀，汇总里保持一致。顺序乱了按用户给的顺序处理，开头一句说明处理了哪几个题号。题干跨页截断的，先说明缺的是哪一段再答。
