# shot-exam

读图，把题目誊下来，一题一题答，最后给一行汇总。

- 保留原题号。图上几题就答几题，不合并、不改号、不漏题。
- 图上有"（不定项选择）""（判断题）"这类标注，按标注来；没标注再看选项和问法。
- 不定项只写一个算错。判断题只写"对"或"错"。
- 每题一句依据，落到公式、定义、年份、条文上。"通常认为"不是依据。
- 递归、边界、溢出、单位换算这类题，真算一遍再写答案。
- 拿不准或有两种口径，答案照给，后面补一句备选，比如 `C（只讲到 42 号道岔的教材记 160 km/h）`。
- 图糊到读不出选项，就说读不出，别编。

输出长这样：

```
1. 答案：C
   依据：兰新高铁 1776 km，一次性建成通车里程最长。

2. 答案：BCD
   依据：德国客货混运，新线与既有线改造并举，夜间跑货车。

汇总：1-C 2-BCD
```

题型怎么认、各学科常掉的坑、汇总行的写法，都在 `references/rules.md`。
